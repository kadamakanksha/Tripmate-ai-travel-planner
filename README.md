 # ✈️ TripMate AI - Travel Planner
AI-powered travel itinerary planner built with Google AI Studio, Express.js, Genkit and Gemini.
TripMate AI is an AI-powered travel itinerary planner that generates
personalized day-wise travel plans using Google Gemini.

## 🚀 Features

- AI-generated travel itineraries
- Day-wise trip planning
- Local food recommendations
- Budget tips
- Student-friendly travel plans
- Google AI Studio frontend
- Express.js backend
- Genkit + Gemini integration

## 🛠️ Tech Stack

- JavaScript
- Node.js
- Express.js
- Genkit
- Google Gemini
- Google AI Studio
- Cloudflare Tunnel

## 🏗️ Architecture

Google AI Studio
        ↓
Express.js API
        ↓
Genkit
        ↓
Google Gemini
        ↓
AI-generated Travel Itinerary

## 💡 Example

### Input

Make a 5 day trip from Pune to Japan

### Output

TripMate AI generates:

- Day-wise itinerary
- Places to visit
- Local food suggestions
- Budget tips
